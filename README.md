# Сверка мест

[Скачать последнюю версию](https://github.com/hitarus/ticket-checker-releases/releases/latest)

Версия для друзей: без ИИ и парковок. Схемы и привязки включены, история хранит последние 10 матчей. Оба интерфейса доступны.

## Установка
1. Скачайте EXE из последнего выпуска.
2. Закройте Сверку мест.
3. Запустите EXE и выберите прежнюю папку программы (или отдельную папку для первой установки).
4. Откройте программу через ярлык и подключите Google Chrome.

## Обновления
При новой версии появится уведомление и прогресс скачивания. Когда загрузка закончится, нажмите «Перезапустить и обновить». Программа сохранит состояние, покажет окно установки с прогрессом и откроется снова. Во время операции с матчем перезапуск недоступен.

Выпуски проверяются при запуске и каждые 6 часов. Кнопка «Обновления» запускает проверку вручную. Подпись выпуска и целостность установщика проверяются автоматически. Для скачивания не нужен аккаунт GitHub.
